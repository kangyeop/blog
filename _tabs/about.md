프론트엔드 개발자입니다. AI, 특히 LLM 에이전트에도 관심이 많아서 라인플러스에서 SNS 마케팅 자동 생성 서비스의 에이전트 파이프라인을 설계, 운영하는 일도 함께 하고 있습니다.

이 블로그는 프론트엔드와 AI Agent/LLM 사이를 오가면서 마주친 문제, 그때그때 내린 판단, 그리고 그 과정에서 다시 붙잡게 된 아키텍처 고민들을 기록하는 공간입니다.

## 기술 스택

- **Frontend** React, Next.js, TypeScript, Jotai, Vite, React Query
- **Backend** Nest.js
- **AI / LLM** LangChain.js, LangGraph, Prompt Engineering, 자체 LLM 관측 인프라(OpenSearch)
- **Polyglot** Python (FastAPI, OpenCV, scikit-learn)
